# Source record

Original Friend-Pi implementation against Pi public extension hooks.
No third-party context engine or Agent loop is copied or bundled.

Architecture references: Pi compaction preparation and boundary drafts,
DeepSeekHarness retained-tail/source-event design, and MiMo-Code context
rebuilding/watermark design. Checked revisions and licenses are recorded in the
root source ledger. Pi JSONL entries remain the only original history authority.

Evolution changes (2026-10-07): explicit native/infinite mode boundary, verified
UTF-16 source-fragment retirement, persistent Memory epoch/version receipts,
one optional Memory selection plus one compaction summary, cancellation without
an additional fallback call, and derived-only background drafts. These are
original implementations using the fixed Pi public extension API; no loop,
third-party source closure or authentication code was copied. Source-fragment
helpers are supplied by the ordinary Friend-Pi core library. Tests exercise the
public SDK with offline providers and do not represent GUI or real-model QA.

# Source record

This package contains original Friend-Pi implementation, using Pi's public
extension interfaces and the ordinary Friend-Pi core library. No third-party
memory implementation has been copied or bundled.

Architecture references: DeepSeekHarness session-query (source references and
SQLite search), and Mem0 (separating retrieval, update and deletion). The root
source ledger records checked repository revisions and licenses. Referencing
these designs does not claim their code is incorporated or their hosted
services are required.

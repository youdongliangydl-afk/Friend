# 会话全屏工作台

- 所有新建和已有会话统一使用全屏标签布局，不进入 macOS 系统全屏；取消普通布局和右侧工作台入口。
- 项目与会话统一在左侧分组列表展示：项目标题带文件夹图标，会话缩进排列，当前会话用浅色背景标记；临时会话单独分组。左侧列表支持搜索、归档、项目及同项目会话拖动重排，并可整体收起。新建会话旁的浅色加号创建项目文件夹；项目行的编辑图标直接在该项目中新建会话，更多菜单保留排序等操作。
- 顶部左区提供会话后退、前进与侧栏开关；标签从侧栏分隔线右侧开始，与聊天、工具页和终端共用布局坐标。会话是固定标签，工具页各为单例，网页可有多个标签。加号打开网址和工具入口；重复选择工具会切到原标签。
- 删除对话／轨迹二级导航；右上角轨迹按钮打开单例全屏轨迹标签，沿用原生消息、工具与系统上下文记录。
- 输入框仅在会话页显示，切到文件、网页、终端等工具页后隐藏，草稿与附件保留；顶部会话标签固定显示“会话”。
- 删除任务中心与任务信息卡片；通过左侧会话列表和系统通知返回会话，查看新回复并处理审批。侧栏状态点区分待用户处理和未读结果；延期审批可通过顶部“会话”或侧栏重新打开。
- 常规设置可指定新会话的浏览器登录范围。范围默认值只用于新会话，不覆盖已有会话。
- 对话输入区限制最大宽度；文字区与底部按钮共享外框，窄窗口下控件换行。分支会话同样在主会话区域打开。
- 会话菜单可选浏览器登录范围：整个 Friend 共用、按项目隔离、按会话隔离。更改已有网页的范围需确认重新加载；旧分区登录数据保留，不复制到新分区。
- 浏览器支持 HTTP/HTTPS 网址、导航、刷新、上传、下载及网页弹窗。关闭来源标签时保留尚在下载的宿主，传输结束后清理。下载进度保留到本次应用退出；重启不自动重试下载。
- 布局、标签与网页网址跨重启恢复；浏览器内存中的表单、导航栈和脚本生成的空白弹窗正文不跨重启恢复。终端仍遵循原有不重放命令规则。

## 实现边界

`SessionViewState` 是版本 1 的桌面界面状态，存于 desktop RecordStore 的 `session-ui:<desktop session ID>` 键，与 Pi JSONL 分离。读取旧普通布局记录时，将工具页和终端开关迁为全屏标签，保留浏览器标签身份、网址、登录范围与侧栏状态，并清除旧布局快照。迁移幂等，不改 Pi 历史；旧全局和项目布局偏好统一按全屏解释。

项目排序存于 `project-order`，会话排序存于 `session-order:<project ID>`。会话排序须提交包含归档会话的完整同项目 ID 排列；搜索和归档仅过滤展示，拖动保留不可见条目。未排序的新会话放在前面，已保存的顺序不随模型活动时间变化；菜单及 Alt+Shift+上下键提供拖动替代操作。

会话导航历史由主进程维护，记录本次运行中成功选择的 `{projectId, sessionId|null}`。后退／前进直接恢复空项目壳，不自动选中其最近会话；失败、迟到启动和后台状态更新不增加历史，新导航清除前进分支。历史最多 100 项，不跨重启恢复；各会话的草稿和附件仍独立持久化。

主进程提供 `project.create`、`session.reorder`、`navigation.go`、`session.ui.get/update`、`browser.list/present/navigate/action/cancelDownload`。界面状态更新可以在执行中完成，不改变执行目标、模型、权限或 Pi 消息历史。会话删除同时清理其界面记录与页面实例；共用浏览器分区不因此清空。

BrowserHost 管理 WebContentsView。访客与弹窗强制关闭 Node，开启隔离、sandbox 和 webSecurity，不加载 Friend preload；持久分区由 app、工作目录摘要或会话 ID 决定。弹窗采用 Electron 返回的 WebContents 以保留 opener；页面自行关闭会清理其标签。所有 Friend IPC 仍验证主窗口的主 frame。聊天输入框只在主会话页挂载；主进程不再提供原生浮动输入框的同步入口。共享快照与草稿保存三种权限策略，完整权限控件仍在会话页；临时会话目录外操作仍需显式批准。

原生网页与 DOM 不能靠 z-index 互相覆盖。网页层计算 bounds，并跟随窗口缩放；设置、审批、窄窗口侧栏打开时，隐藏网页层，关闭后恢复。会话切换由主进程统一隐藏旧原生视图，之后按新会话恢复。工作台与终端保持原控制器、文件缓存和进程管理。

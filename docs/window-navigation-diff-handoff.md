## 行为

- 标签栏可横向滚动，隐藏滚动条，保留方向键/Home/End 与当前标签自动进入视野。横向与 Shift 滚轮使用原生行为，普通纵向滚轮转为横向移动。
- 顶部导航、侧栏边缘、会话标题和空会话背景使用原生拖窗。已有消息时，仅正文列外留白边距可拖动；轮次索引、正文、滚动条、计划审批和输入控件保持正常操作。新标签页内容周围留白与 Diff 顶部专用空白条可拖窗。
- 侧栏顶部文件夹打开项目，移除底部重复入口。工具入口和对应标签使用同一套不同 SVG 图标。
- Diff 支持统一/并排、行号、语言着色、增删统计、折叠与展开已保存的上下文。代码文本仍可选择，超长行可滚动或换行。
- “上一轮”只读冻结的会话变更快照；当前文件被修改或删除，不改变该历史。旧快照缺少的上下文不可从当前文件补齐。
- 未提交/未暂存/已暂存读取当前 Git 范围；已提交显示 HEAD 第一父提交 → HEAD，根提交显示空树 → HEAD。分支比较仅接受本地枚举且冻结 SHA 的引用，展示唯一 merge-base → HEAD。
- Git 数据读取禁用 external diff/textconv；无网络、checkout、暂存、重置或丢弃操作。二进制、大文件、文件数和响应预算不足均保留明确边界。单补丁超过 128K 行或字节预算时，在生成行对象前即返回统计与正文省略提示；合法旧快照也受此限制。
- 切换工作区/范围/分支时，旧请求不能覆盖新结果或解除新请求的等待状态。

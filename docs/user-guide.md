# 使用说明

1. 打开 Friend-Pi.app，在左下“设置”保存内置供应商 Key，或者填写自定义供应商、兼容 API、地址和模型 ID，再打开项目并新建会话。认证仅存于本机独立目录，不需要把 Key 发给开发者。
2. Single 在当前项目执行。开启“先规划”后只读探索，中央卡片提供计划全文、要求修改、批准并执行和退出。批准绑定当前计划版本，修改后需重新批准。
3. Swarm 在输入框选择后提出目标。工作台只看本轮依赖关系和状态；详细任务、检查、消息、成果与返工在设置的协作管理。Git 写入需要干净基线，保留用户未提交改动。
4. 暂停/停止保留成果。停止先显示“正在停止”，收到终止回执后才结束；未知副作用检查后显式接续。复核只使受影响任务和下游失效，独立通过的成果保留，自动返工最多两轮。
5. Expert 工作台显示当前实际采用的专家、方向和 Skill；专家库编辑、选择、版本和客观验证放在设置。任务冻结版本及权限，采用只能收紧工具范围。
6. Memory 工作台显示本轮真实提供或读取的记忆版本及来源，区分上下文、请求准备和响应观察。项目经验与个人偏好自动学习，无需点击候选采用。纠正一个要求只替代该事实，同条原话里的其他要求保留；高级纠正、停用和遗忘在设置。
7. 默认 Pi 原生压缩。在设置打开“无限上下文”后，压缩时结合有效历史记忆选择保留片段和摘要；后台只准备草稿，前台负责验证和保存。没有上下文工作台页，高级历史回查和诊断在设置。
8. 文件页提供只读文件树、可关闭的预览标签、代码/文本/Markdown/图片、路径与行号定位，大文本分段读取；其他格式系统打开。Diff 可按文件展开，切换行内/双栏和工作区/未暂存/已暂存/本轮期间。本轮基线失效会明确提示。
9. 新建会话旁的时钟切换当前项目近期/已归档；普通卡右侧快捷归档，归档卡右侧快捷删除，普通会话删除在右键菜单。删除统一预览和一次确认，执行中拒绝删除。恢复保留原会话继续发送。
10. 自动学习是一个常驻 Node 服务和串行队列，前台可同时工作。红色关窗隐藏窗口，Dock 再打开；⌘Q/菜单退出停止进程并保存阶段，下次启动接续。不安装系统后台服务。设置可暂停学习、指定后台模型、查看等待配置和失败。

右上两个镜像分栏图标分别控制左侧会话栏和右侧统一工作台，左右分隔线支持拖动及键盘调宽并保存比例；窄窗口按需收起会话栏。会话卡片依据原生结算和协作调度显示状态，完成标记表示本轮执行结束。会话左侧短线入口支持预览、书签及定位。设置支持搜索、全局默认、项目覆盖、供应商能力和测试连接、当前快照与待生效配置；新默认值不改写已有执行快照。`⌘ N` 新会话、`⌘ Enter` 发送；消息输入中的 Enter 保留换行。

首次打开桌面上的项目时，macOS 可能要求允许访问“桌面文件夹”。请在系统提示中允许，或在“系统设置 → 隐私与安全性 → 文件与文件夹 → Friend-Pi”开启该目录。若等待授权期间会话初始化已超时，授权后重新打开该会话；不会自动重放任务。

冷启动读取原生 Pi 历史和插件业务记录，不自动继续未完成副作用。运行时退出时重新打开会话，再显式发消息或接续任务图。源文件缺失或项目基线变化会显示错误并保留工作区。

数据和备份：客户端数据在 `~/Library/Application Support/Friend-Pi`，包括 `pi/auth.json`、`pi/models.json`、`sessions/*.jsonl`、`plugins.sqlite` 和 Swarm 工作区。退出应用后整体备份该目录及项目。认证文件含敏感信息，不应提交到 Git。测试使用独立 `FRIEND_PI_DATA_DIR`。

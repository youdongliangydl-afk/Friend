# 使用说明

1. 打开 Friend-Pi.app，在左下“设置”保存内置供应商 Key，或者填写自定义供应商、兼容 API、地址和模型 ID，再打开项目并新建会话。认证仅存于本机独立目录，不需要把 Key 发给开发者。
2. Single 在当前项目执行。计划模式只读取；计划满意后关闭“先规划”再发送实施要求。输入区的计划和协作选择用于下次发送，随当前会话草稿保存；执行时固定本轮快照。模型或插件配置修改需要当前执行空闲。
3. Swarm 既可在输入框选择后直接提出目标，也可在工作台创建带依赖、范围和检查命令的任务图。Git 写入先清洁基线；不要删除未提交改动来绕过检查。
4. 在任务图查看成员、尝试、消息收据和共享文件版本。暂停／停止保留成果，未知尝试必须检查后确认接续。“可整合”表示检查和独立复核通过；自动整合仍会重新检查原项目基线。
5. Expert 工作台采用自动专家或选择明确专家，编辑生成新版本，历史可比较和回滚为新版本。方法候选和验证基准独立管理；可以暂停后台验证。
6. Memory 工作台支持中文搜索、查看来源和版本、纠正及停用。明确保存个人偏好才会跨项目采用。遗忘会使相关派生经验失效，并留下重新学习抑制记录。
7. 上下文工作台可查看当前目标、约束、决定和未完成现场。空闲时“整理上下文”调用真实 Pi 压缩；历史搜索与前后文直接读取 JSONL。
8. 文件面板输入项目内相对路径，Diff 显示 Git 当前改动。附件通过原生文件选择器选择，文本与图片限制在发送时检查。

窗口右上图标打开或关闭相应面板，左右分隔线支持拖动及键盘调宽并保存比例；窄窗口按需收起会话栏。会话卡片依据原生结算和协作调度显示状态，完成标记表示本轮执行结束。会话左侧短线入口支持预览、书签及定位。设置集中供应商认证、新会话默认选项和数据目录说明；新默认值不改写已有执行快照。`⌘ N` 新会话、`⌘ Enter` 发送；消息输入中的 Enter 保留换行。

首次打开桌面上的项目时，macOS 可能要求允许访问“桌面文件夹”。请在系统提示中允许，或在“系统设置 → 隐私与安全性 → 文件与文件夹 → Friend-Pi”开启该目录。若等待授权期间会话初始化已超时，授权后重新打开该会话；不会自动重放任务。

冷启动读取原生 Pi 历史和插件业务记录，不自动继续未完成副作用。运行时退出时重新打开会话，再显式发消息或接续任务图。源文件缺失或项目基线变化会显示错误并保留工作区。

数据和备份：客户端数据在 `~/Library/Application Support/Friend-Pi`，包括 `pi/auth.json`、`pi/models.json`、`sessions/*.jsonl`、`plugins.sqlite` 和 Swarm 工作区。退出应用后整体备份该目录及项目。认证文件含敏感信息，不应提交到 Git。测试使用独立 `FRIEND_PI_DATA_DIR`。

# 使用说明

1. 打开 Friend-Pi.app，在左下“设置 → 模型”填写供应商、具体型号、凭证和可选兼容接口，保存后点击该型号的“测试连接”。只有测试通过的型号才能发送消息；未配置时输入区提供“配置模型”快捷入口。认证仅存于本机独立目录，不需要把 Key 发给开发者。
2. Single 在当前项目执行。开启“先规划”后只读探索，中央卡片提供计划全文、要求修改、批准并执行和退出。批准绑定当前计划版本，修改后需重新批准。
3. Swarm 在输入框选择后提出目标。工作台只看本轮依赖关系和状态；详细任务、检查、消息、成果与返工在设置的协作管理。Git 写入需要干净基线，保留用户未提交改动。
4. 暂停/停止保留成果。停止先显示“正在停止”，收到终止回执后才结束；未知副作用检查后显式接续。复核只使受影响任务和下游失效，独立通过的成果保留，自动返工最多两轮。
5. Expert 工作台显示当前实际采用的专家、方向和 Skill；专家库编辑、选择、版本和客观验证放在设置。任务冻结版本及权限，采用只能收紧工具范围。
6. Memory 工作台显示本轮真实提供或读取的记忆版本及来源，区分上下文、请求准备和响应观察。项目经验与个人偏好自动学习，无需点击候选采用。纠正一个要求只替代该事实，同条原话里的其他要求保留；高级纠正、停用和遗忘在设置。
7. 默认 Pi 原生压缩。在设置打开“无限上下文”后，压缩时结合有效历史记忆选择保留片段和摘要；后台只准备草稿，前台负责验证和保存。没有上下文工作台页，高级历史回查和诊断在设置。
8. 文件页提供按需展开的目录树、多文件标签和 CodeMirror 编辑器；`⌘S` 保存，未保存关闭可选择保存／放弃／取消，外部修改时确认重载或覆盖。Markdown 本地图与相对链接、图片和隔离 HTML 可预览；大文本分段只读，其他格式系统打开。Diff 可按文件展开，切换行内/双栏和工作区/未暂存/已暂存/本轮期间。本轮基线失效会明确提示。
9. 新建会话旁的时钟切换当前项目近期/已归档；普通卡右侧快捷归档，归档卡右侧快捷删除，普通会话删除在右键菜单。删除统一预览和一次确认，执行中拒绝删除。恢复保留原会话继续发送。
10. 自动学习是一个常驻 Node 服务和串行队列，前台可同时工作。红色关窗隐藏窗口，Dock 再打开；⌘Q/菜单退出停止进程并保存阶段，下次启动接续。不安装系统后台服务。设置可暂停学习、指定后台模型、查看等待配置和失败。

右上两个镜像分栏图标分别控制左侧会话栏和右侧统一工作台，左右分隔线支持拖动及键盘调宽并保存比例；窄窗口按需收起会话栏。会话卡片依据原生结算和协作调度显示状态，完成标记表示本轮执行结束。会话左侧短线入口支持预览、书签及定位。设置支持搜索、全局默认、项目覆盖、供应商能力和测试连接、当前快照与待生效配置；新默认值不改写已有执行快照。`⌘ N` 新会话、`Enter` 发送；`⌘ Enter`／`Shift Enter` 换行，输入法确认候选不会发送。编辑器的 `⌘S` 只保存文件，终端 Enter 执行命令。

首次打开桌面上的项目时，macOS 可能要求允许访问“桌面文件夹”。请在系统提示中允许，或在“系统设置 → 隐私与安全性 → 文件与文件夹 → Friend-Pi”开启该目录。若等待授权期间会话初始化已超时，授权后重新打开该会话；不会自动重放任务。

冷启动读取原生 Pi 历史和插件业务记录，不自动继续未完成副作用。运行时退出时重新打开会话，再显式发消息或接续任务图。源文件缺失或项目基线变化会显示错误并保留工作区。

数据和备份：客户端数据在 `~/Library/Application Support/Friend-Pi`，包括 `pi/auth.json`、`pi/models.json`、`sessions/*.jsonl`、`plugins.sqlite` 和 Swarm 工作区。退出应用后整体备份该目录及项目。认证文件含敏感信息，不应提交到 Git。测试使用独立 `FRIEND_PI_DATA_DIR`。


## 本批客户端入口

- 点击固定的“临时会话”入口直接输入；首次发送会在 `~/Documents/Friend/<会话编号>` 分配独立子目录。在设置 → 常规修改临时会话默认目录，仅影响新会话；历史、已保存文件和输入框草稿保留。工作台显示当前子目录；不提供临时会话转换项目。目录外的 Agent 文件修改，即使选择“所有权限”也必须逐次批准；无法确认写入范围的命令同样需要批准。旧会话保留原目录并执行相同边界。
- 拖拽项目按钮显示落点，在栏边缘停留可滚动；右键菜单左移／右移，或 Alt Shift 左／右。触控板横滑、鼠标滚轮和溢出箭头均可浏览项目。
- 文件区右上“放大”扩展阅读／编辑空间，分隔线可调宽。切换项目、隐藏工作台或切到 Diff 后，当前应用内的文件标签和未保存编辑仍保留。退出前请保存文件；文件编辑草稿不写入磁盘。
- 顶栏“内嵌终端”或 Ctrl 反引号打开面板，首次打开无会话时会创建临时会话并保留输入框草稿。点击“＋”创建终端，停靠菜单切换底部／右侧／浮窗；拖动浮窗标题和尺寸边缘调整位置。
- 服务终端显示“Agent 控制”。读取、复制、聚焦、滚动和改变尺寸不接管；键入、粘贴或输入法实际输入会先接管。接管后 Agent 输入与输出读取均拒绝，点击“交还 Agent”更新控制版本。
- 计划模式只允许 Agent 列出／读取已有且仍由 Agent 控制的服务终端。用户可独立使用普通终端。隐藏面板保留进程，标签关闭会停止所属进程，退出应用停止全部终端；下次启动显示记录，命令不重放。

设置入口固定在会话侧栏左下角。会话列表单独滚动，空会话或少量会话不会改变设置按钮的位置。


设置窗口分为“常规／模型／记忆／扩展”，标题和底部按钮固定，正文独立滚动。切换栏目保留模型表单；常规页保留全局／项目覆盖、搜索和默认能力。模型卡片显示已选型号和实际支持的思考等级，滑杆松手或键盘操作结束后保存；不支持思考的型号显示“不可调节”。重置按钮回到“不思考”。

只列出明确保存的具体型号；供应商 Key 或环境变量不会导入整个型号目录。旧 `pi/models.json` 中明确配置的型号会迁移为“待验证”。每个型号单独测试：成功状态与有效型号、地址、协议和认证摘要绑定；修改同供应商配置使已通过状态失效，须重新测试。失败或超时保留输入草稿，拒绝发送及批准执行；旧会话仍可阅读。前台、插件模型调用、Swarm 成员和后台学习使用同一校验规则。独立原生 Pi 插件不受桌面策略影响。

备份时一并保留 `pi/model-readiness.json`；其中仅含验证摘要与状态，不含明文 Key。测试结果不表示永久网络可用，实际调用仍可能因服务或网络故障失败。

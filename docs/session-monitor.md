# 会话监控栏

普通会话与会话全屏：轮次/速度、Token/缓存显示在标题右上角，上下文圆圈显示在模型左侧。统计在步骤结束、模型或上下文变化时更新，冷启动从原生历史恢复。

- 轮次 / 步骤：新记录按公开执行边界归并，工具执行结束后确认步骤关闭；自动重试归入同一步。旧记录按原生输入祖先与模型回复回溯，详情明确首 token 计时缺失。
- TPS：有首 token 计时步骤的输出 tokens 总和 / 解码秒数总和，排除首 token 等待；缺计时隐藏。点击性能统计查看模型/工具累计耗时、平均首 token、TPS。
- Tokens：Pi SDK 对完整原生会话历史的未缓存输入 + 缓存读取 + 缓存写入 + 输出；包含 SDK 已记录的压缩及工具用量，不含独立成员会话。点击查看精确分桶。缓存命中 = 缓存读取 / 三项输入合计；无输入隐藏，部分命中不会进位成100%。
- 上下文：Pi SDK 当前分支上下文估算 / 当前窗口容量，与累计用量独立；容量/估算未知时隐藏。悬停200ms显示说明，点击查看估算已用/容量与占用条。

时间、用量和上下文详情互斥，外点/Escape关闭，键盘可操作，滚动/resize重新定位。工具浮动输入仍保留最简控件。没有额外模型请求、采样后台任务、外部遥测，也不复制会话文本。

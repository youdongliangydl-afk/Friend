# 全局自定义指令

在 **设置 → 自定义指令** 中查看、编辑完整的 Friend 指令，然后点击保存。未设置自定义内容时，使用用户提供的完整默认正文，设置页也展示这份全文。默认正文由 [`DEFAULT_CUSTOM_INSTRUCTIONS`](../packages/core/src/custom-instructions.ts) 统一定义，不使用摘要或只提取部分要求。

保存非空自定义内容时，这一整段内容替换默认指令，不与默认正文拼接。清空并保存（含仅空白内容）会恢复完整默认指令；清空不表示停用全局指令。支持取消修改、保存失败重试与并发版本冲突提示。未保存的指令草稿会阻止关闭设置，可切换分类后返回继续编辑。

指令在当前 Friend 数据目录全局保存，不随项目设置覆盖或重置。覆盖新建和已有的交互会话，以及 Team / Swarm 成员、成员讨论与独立复核。保存后从下一次新执行生效；正在进行的执行及其排队续写保持原配置。重启应用后仍保留。

通过 Pi 公开 `before_agent_start` 扩展链追加到每轮系统提示词，保留原有宿主提示词、权限和工具协议。提示明确标记本次读取的当前版本，避免历史偏好、旧回答格式或工具返回的旧标记覆盖更新后的指令。Pi 继续独占模型执行循环及原生 JSONL 历史；不会复制或改写聊天消息。自定义指令是用户偏好，本轮明确要求优先，不能赋予新的工具权限。内部后台学习与模型连接检测继续使用各自的结构化协议。

持久化使用已有 `RecordStore('desktop')` 的 `custom-instructions` 记录，文本与全局模型默认设置分开保存。读取和保存返回原始 `{text, revision}`：从未保存时为 `{text: '', revision: 0}`，保存空文本后仍保留对应 revision；运行时和设置界面根据空值选择完整默认正文。更新使用 revision 的事务比较写入；过期写入保留草稿并要求重新读取，不静默覆盖。自定义文本最多 32,000 个 UTF-16 字符。

默认指令和自定义指令均通过公开 `before_agent_start` 钩子进入系统提示词的当前指令区块，再通过公开 `context_with_system` 钩子为模型请求追加一次临时 custom 设置提醒。两处各包含一次本次执行冻结的完整有效正文，不写入原生历史，不修改原消息或工具顺序。清空后的新执行恢复默认正文，并明确撤销仅来自旧自定义偏好的固定首行、前缀或后缀；不会继续注入旧自定义正文。revision 为 0 的首次执行同样使用完整默认指令。

验证入口：

- `tests/custom-instructions.test.ts`：持久化、校验、过期写入与每次新执行刷新。
- `tests/custom-instructions-panel.test.ts`：生产组件的加载、保存、失败、取消、清空和草稿关闭保护。
- `tests/sdk-worker.test.ts` 的 `custom instructions reach final provider payload`：最终供应商 HTTP 请求中的默认全文、整段覆盖、清空恢复默认、旧会话冷启动与实际 Team 成员继承，以及临时设置提醒不进入原生历史。

开发验收须另行绑定固定候选、Pi SHA、客户端制品摘要，以及真实 Computer Use 和明确配置的真实模型结果。远端 PR 与 main 合码由指定集成会话处理。

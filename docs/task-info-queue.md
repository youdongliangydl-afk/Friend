# 任务信息与排队消息

- 主会话的「对话」页右上显示任务信息：待处理事项、执行状态、Todo。卡片只读，由 Agent 用 `friend_todo read/update` 维护；简单任务无需生成清单。执行结束不自动勾完剩余项，Todo 也不代替成果验收。
- 新一轮独立清单；运行中补充和自动接续沿用原清单。用户收起后保持，正常结束且无未完项时自动收为摘要。工具、轨迹和成员页隐藏卡片。
- 运行中 Enter 将消息排入输入框上方。支持引导、删除、行内编辑、移入侧边聊天草稿；编辑不覆盖主输入框草稿，原始附件在入队时固定。
- 「关闭排队」暂停自动发送；「恢复排队」恢复。停止任务或重启后保留队列并暂停。正在交付的消息不可编辑或删除；发送结果不明确时显示待确认，绝不自动重发。
- 本轮主 Agent、协作及有限后台任务收敛后，用户队列先于自动接续。未完成长期目标由队列机制挂起、解除当前目标绑定，队列任务独立执行；队列正常完成后恢复原目标、原 run、进度和 Todo。手动停止/替换目标、失败、未知现场或预算不足时不自动恢复。
- 侧边聊天从点击时最近完整的已提交上下文分叉，不复制流式半条消息或未配对的工具调用。正文和附件草稿保存成功后才移出源队列，不自动发送。项目侧聊共享项目目录；临时侧聊新建临时目录，不复制源文件树。
- 关闭侧聊保留会话和草稿，可从会话列表继续。侧聊不接管主会话的目标、队列、Todo、后台进程或变更快照；与右侧工作台共用区域。

## 实现与证据

Pi 公共 SDK 继续独占模型执行和正式 JSONL 历史。`friend-pi.todo.v1` 是原生清单快照；`friend-pi.sidechat.origin.v1` 标出继承上下文边界。输入队列只保存未发送 payload 与交付状态，确认 native `friend-pi.input.v1.queueId` 后删除；重启先对账，无法确认的交付保持 unknown。单项动作绑定消息 ID/revision，移出侧聊通过持久 target ID 与幂等草稿交接，响应丢失不会让源消息重新自动执行。

GUI 与原生浮动输入框共用 SessionComposer、队列控制器和菜单/编辑状态。统计、上下文环、工具阅读位置与冻结 Diff 保留现有实现。队列或 Todo 更新不重挂载主对话。

开发测试与截图在工作树 `.artifacts/task-info-qa/`。最终验收由「验收：集成」会话 `01a11f54-ee7d-7c23-8b6e-211cc4107047` 对单一合并候选重新打包并执行 Computer Use、真实模型与相关回归，开发截图不替代最终验收。

## 集成修复

- 未确认的入队提交在客户端保存稳定编号；即使原消息已消费且会话空闲，重试也先按编号对账，不重新发送。侧聊首发与后续排队共用此入口，持久入队与草稿消费原子完成。
- 侧聊在第一次 IPC 前保存目标意图；同目标的 prepare、分叉、草稿安装均可重试。临时目录属于该意图并保持不变；草稿安装收据在发送后仍保留，旧交接不复活已消费草稿。
- 原目标恢复只在独立队列任务成功收敛后进行；未完成步骤、暂停图、阻塞目标、失败及未知状态保持暂停。手动操作先撤销并等待正在恢复的配置事务；Pi 公共 prompt preflight 在真正启动前再次验证停止代次。
- 并行验收安装包可用 `package:mac -- --app-name NAME --bundle-id ID` 指定唯一应用身份；默认产品身份保持不变。最终报告必须绑定该实例实际制品哈希。

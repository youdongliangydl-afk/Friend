# Friend 五项交互开发说明

基于 `main@346b358d20c63a28a55818be0b9557446cfd4bc8`，对应调研报告的 03、13、19、24、27。开发分支 `codex/wind-five-ux-20261011`；此分支交付开发候选，由指定集成会话最终验收和合码。

## 使用方式

- **模型分组**：输入区打开模型菜单，切到模型列表，按实际供应商分组。组内顺序、连接状态和思考强度沿用现有行为。
- **批量提问**：主助手调用 `friend_questions`，会话内逐题填写、返回修改、复核并提交全部答案。可选题可跳过；未操作的选项不是答案。收起卡片或切换会话保留本次应用运行的草稿；没有自动倒计时。取消不发送草稿，停止或退出使旧问题失效。正式回答由 Pi 原生工具结果保存并显示只读摘要。
- **任务图**：Swarm 模式打开“任务”，查看工作流或独立 Swarm 依赖图。拖动空白平移，按钮缩放、适配全部，小地图定位；点击节点查看详情和队友入口。画布获得焦点时，方向键平移、加减号缩放、0适配全部。浏览操作不启动执行；原执行控制保留。
- **记忆管理**：设置→记忆，选择本项目、个人或全部（本项目＋个人）。卡片默认摘要，正文与管理操作按需展开；候选和失效记录单独折叠。本轮实际提供的记忆工具页保持原含义。
- **Diff**：文件地图显示路径、状态和增删比例；右侧只显示选中文件。区块选择和前后导航限当前文件；长内容定位自动切换分页。窄窗使用顶部文件选择。历史正文缺失、超限与二进制状态明确提示。

## 原生提问接口

```json
{
  "v": 1,
  "title": "确认交付要求",
  "questions": [
    {"id":"format","type":"single","title":"交付形式","required":true,"options":[{"id":"web","label":"网页"},{"id":"doc","label":"文档"}],"allowOther":true},
    {"id":"capabilities","type":"multiple","title":"需要哪些能力","required":true,"options":[{"id":"mobile","label":"移动端"},{"id":"offline","label":"离线"}]},
    {"id":"notes","type":"text","title":"补充说明","required":false}
  ]
}
```

每组 1–12 题。题目和选项使用唯一稳定 ID；宿主验证题型、选项、必答和响应身份。结果状态为 `answered/cancelled/interrupted`；回答通过一次原生 toolResult 进入 Pi JSONL，不额外创建用户消息。同一会话按宿主序号处理问题组。Plan 模式允许澄清，成员仍由主助手汇总问题。

`dialog.respond` 绑定原请求、运行与代次；`dialog.status` 为只读状态核对。宿主合并重复提交，并在结算事件已确认而最后 IPC 回执丢失时返回核对结果。普通单条权限审批继续采用原有期限。

## 实现与验证边界

- 图使用 React、SVG、Pointer Events，无新增依赖；工作流定义提供完整节点，后台执行图补充当前尝试、队友和成果。桌面路由 ID 与 Pi 原生会话 ID 分别使用，不能互换。
- Diff 地图复用已有数据；历史审阅按所选文件懒读冻结正文。区块按原三行上下文折叠边界划分，展开上下文不改变计数。
- 专属样式统一从 renderer 入口加载。未修改依赖、锁文件、Pi 调度循环、Memory 存储或 Git 比较算法。
- 验收证据保存于 `.artifacts/five-ux/`，包含测试、独立客户端身份、模型原生记录核对、截图和前后对照。渲染示意、真实 GUI、真实模型和最终远端合码分别记录，不以任一项替代其他项。
